# Spec+RFC 统一模板

Spec 和 RFC 作为一个单一连贯工件产出。所有标题翻译为用户语言，ID（FR-001 等）保持不变。

保存为 Markdown 文件时，文档顶部必须包含元数据块：

```md
> 文档生成时间：yyyy-MM-dd HH:mm:ss 时区
> 生成方式：spec-rfc
```

修订已保存文档时，必须保留原 `文档生成时间`，并新增或更新：

```md
> 最近修订时间：yyyy-MM-dd HH:mm:ss 时区
```
