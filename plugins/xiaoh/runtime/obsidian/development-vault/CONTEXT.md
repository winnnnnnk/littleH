# 开发知识库上下文

这是小H配套的通用开发知识库。初始内容全部为空白模板，不包含任何客户或项目事实。

## 使用原则

- 一个项目建立一个项目首页，并从项目首页链接需求、方案、决策、验证和工作记录。
- 跨项目可复用的领域知识独立维护，不混入单个项目结论。
- 任务完成或形成稳定阶段结论时，由小H立即整理“做了什么、为什么这样做、验证结果、风险和后续”；业务项目写入项目工作记录并刷新项目进度，全局Agent能力和Playbook平台分别写入`07-工作记录/全局能力`与`07-工作记录/平台`，不得等待每日定时任务补写。
- 即时记录使用稳定任务ID、阶段ID和已验收修订生成收口键；缺少稳定身份时停止写入，避免重复或错误归档。
- 每日定时任务只推送已经即时收口的成果，并报告遗漏的收口，不承担任务总结或项目总结。
- 尚在讨论中的内容可以放入收件箱；未经确认不升级为长期事实。
