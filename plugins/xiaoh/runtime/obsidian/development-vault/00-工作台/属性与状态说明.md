# 属性与状态说明

## 核心属性

| 属性 | 作用 |
|---|---|
| `type` | 区分项目、任务、进度、知识、决策、排障和工作记录 |
| `project` | 归属项目；跨项目内容可以为空 |
| `domain` | 业务或能力领域，例如 `pki`、`agent-governance` |
| `status` | 生命周期阶段 |
| `health` | 当前健康状态 |
| `owner` | 下一动作责任人 |
| `next_action` | 当前最明确的一步 |
| `needs_user_decision` | 是否真正需要用户确认业务结果 |
| `focus` | 是否进入今日重点 |
| `priority` | 今日重点中的相对优先级 |
| `updated` | 当前页面事实最近更新时间 |
| `verified_at` | 页面事实最后核验日期 |

## 生命周期

| 状态 | 含义 |
|---|---|
| `captured` | 已记录，尚未完成分析 |
| `clarifying` | 小H正在核对需求或事实 |
| `ready` | 已具备执行条件 |
| `in_progress` | 正在推进 |
| `blocked` | 存在真实阻塞 |
| `accepted` | 当前目标或阶段已验收 |
| `archived` | 不再进入当前工作视图 |
| `candidate` | 等待知识评审的候选 |

## 健康状态

- `normal`：按当前路径可继续。
- `at_risk`：仍可推进，但存在待处理风险。
- `blocked`：下一步无法继续，必须先解除阻塞。

## 迁移规则

历史状态保存在 `legacy_status`，新视图只读取标准 `status`。状态归一化不改变原页面中的业务结论和证据。
