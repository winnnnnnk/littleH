# 开发知识库规则

- 本 Vault 保存人类可读的稳定结论，不保存密码、令牌、私钥或生产凭据。
- 工作台、项目进度和每日记录管理当前执行与证据；它们不等于正式知识。
- 正式知识只归入一个范围：项目知识写入`01-项目/<project>/知识`，领域知识写入`02-领域知识`，可复用方法写入`03-可复用方法`，个人工作系统写入`90-个人系统`。
- 知识候选必须经证据核对和知识晋升流程后才能成为正式知识；项目特例不得直接推广为跨项目规则。
- 原始运行证据、临时日志和真实会话保留在任务证据目录，不复制到 Obsidian。
- 只有经xiaoh验收的结论才进入长期知识；未知事实明确标记，不凭空补全。
- 写入目标只能从`~/.xiaoh/config.json`的`obsidian_vault`取得；不得根据当前打开的Vault或历史路径推断。写回结果必须同时报告Vault根路径和实际文件绝对路径。
