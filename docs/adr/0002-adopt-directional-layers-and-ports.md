# ADR-0002：采用单向分层和 Ports/Adapters

- 状态：已接受
- 日期：2026-08-01
- 来源：`docs/spec-rfc/xiaoh-4.0.0-runtime-rewrite.md`

## 背景

当前运行时虽然已经分成多个文件，但星号导入和交叉依赖使模块边界不清晰。领域规则与文件系统、环境变量和进程调用混在一起，核心行为难以隔离测试。

## 决策

运行时采用 domain、application、ports、adapters、installation、diagnostics、capabilities 和 interface 分层。领域层不依赖具体外部系统，所有副作用通过 Port，由 Adapter 实现。

模块必须显式导入，依赖方向由自动检查约束，不允许循环依赖。

## 备选方案

- 继续使用公共 `common.py` 和星号导入：迁移成本低，但无法形成可靠边界。
- 为每个函数创建独立文件：文件更小，但会产生浅模块和大量内部接口。

## 后果

- 核心规则可以在不访问真实本机的情况下测试。
- 常见修改更集中，跨模块影响更容易判断。
- 初始重写需要明确 Port 粒度，并避免为单一实现创建无价值抽象。
