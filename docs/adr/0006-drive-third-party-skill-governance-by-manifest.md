# ADR-0006：第三方 Skill 治理由 Manifest 驱动

- 状态：已接受
- 日期：2026-08-01
- 来源：`docs/spec-rfc/xiaoh-4.0.0-runtime-rewrite.md`

## 背景

当前第三方 Skill 治理把来源提交、Skill 名称、决策和文件摘要大量硬编码在 Python 函数中。新增来源或重新审核上游时，需要修改校验实现，职责和证据没有分离。

## 决策

第三方来源、许可证、固定提交、逐 Skill 决策、上游摘要和改造后摘要由版本化 Manifest 描述。通用校验器只验证 Schema、路径安全、摘要和决策一致性。

上游提交变化必须重新审核。系统不得自动从网络覆盖已经审核的 Skill。

## 备选方案

- 继续为每个来源硬编码规则：短期直接，但扩展和复核成本持续增长。
- 每次运行都读取上游最新内容：更新及时，但破坏可重复性和供应链控制。

## 后果

- 来源事实与校验逻辑分离，审计更清晰。
- Manifest Schema 必须严格版本化并接受负向测试。
- 发布前仍需重新核对固定上游提交。
