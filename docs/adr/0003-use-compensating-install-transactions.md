# ADR-0003：采用跨根补偿安装事务

- 状态：已接受
- 日期：2026-08-01
- 来源：`docs/spec-rfc/xiaoh-4.0.0-runtime-rewrite.md`

## 背景

XiaoH 安装会修改 Codex Home、XiaoH 配置和 Obsidian Vault。这些目标可能位于不同文件系统，无法由一个文件系统原子操作覆盖。仅在写入前复制备份不能保证中断后的恢复。

## 决策

每个受管根尽量采用局部原子切换，跨根一致性通过持久化事务日志、恢复清单和补偿恢复实现。

事务记录计划写入、实际写入、旧摘要、新摘要、阶段、失败和恢复结果。第一次写入后的失败必须进入 `rolled_back` 或 `recovery_required`，不得标记成功。

## 备选方案

- 宣称跨全部路径全局原子：无法满足真实文件系统条件。
- 只创建备份，不实现事务和恢复：实现简单，但仍会留下半安装状态。

## 后果

- 安装中断后可以判断并验证恢复结果。
- 事务模型和故障注入测试的实现成本增加。
- 未来本机安装必须先形成完整恢复清单。
